개인정보처리방침

업로더(이하 «앱»)는 운영자 본인이 소유한 유튜브 채널을 관리하기 위한 개인용 프로그램입니다.

사용하는 정보

앱은 Google 계정 연결로 받은 권한으로 다음 일만 합니다: 영상 올리기, 채널 영상 목록 읽기, 영상 공개 상태 바꾸기.

보관과 공유

로그인 정보(토큰)는 운영자의 컴퓨터에만 저장되며, 외부 서버로 보내거나 제3자와 공유하지 않습니다. 광고나 분석 목적으로 쓰지 않습니다.

Google API 서비스 사용자 데이터 정책

앱이 Google API로 받은 정보의 사용과 전송은 Limited Use 요구 사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

권한 철회

https://myaccount.google.com/permissions 에서 언제든 앱의 접근 권한을 해제할 수 있습니다.
